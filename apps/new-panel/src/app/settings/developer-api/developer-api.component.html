شما می‌توانید با استفاده از پروتکل OpenAPI و کلیدهای دسترسی (API Keys)، مجموعه‌ای از ابزارها و هوش مصنوعی‌ها مانند Gemini Spark را به فروشگاه خود متصل کنید. پس از اتصال، هوش مصنوعی می‌تواند طبق دسترسی‌های مشخص شده، اطلاعات سفارش‌ها، منو و گزارش‌های فروش را بخواند یا ویرایش کند.

مراحل راه‌اندازی در پنل هوش مصنوعی:

  1. ابتدا یک کلید دسترسی (API Key) جدید با دسترسی‌های مورد نیاز در انتهای همین صفحه بسازید.
  2. لینک مشخصات OpenAPI بالا را در بخش پیکربندی هوش مصنوعی وارد کنید.
  3. نوع احراز هویت (Authentication) را روی API Key و در هدر (Header) با نام X-Shop-API-Key تنظیم کنید.
  4. مقدار کلید تولید شده را به عنوان مقدار هدر وارد کنید. کار تمام است!

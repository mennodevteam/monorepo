تنظیم کردن MCP

اتصال دستیار هوشمند (MCP)

با تعریف کلیدهای دسترسی (API Keys) و اتصال لینک مشخصات OpenAPI به عامل‌ها و دستیارهای هوش مصنوعی مانند Gemini Spark، می‌توانید کارهای مدیریتی فروشگاه خود را با دستورات متنی ساده انجام دهید. دستیار هوشمند بر اساس دسترسی‌های تعیین‌شده می‌تواند اطلاعات سفارش‌ها، کاتالوگ و گزارش‌ها را بخواند یا ویرایش کند.

آدرس مشخصات API (OpenAPI Specification URL)

این لینک را در بخش Actions ربات هوش مصنوعی خود وارد کنید تا ربات با تمام متدها و ساختار داده پنل شما آشنا شود.

لینک اتصال مستقیم سرور MCP (SSE)

از این لینک می‌توانید برای اتصال مستقیم و بدون واسطه (بدون نیاز به ماژول یا پل واسط محلی) به دستیارهای هوشمند استفاده کنید. برای راهنمایی بیشتر، بخش «مراحل راه‌اندازی» در زیر را مطالعه کنید.

مراحل راه‌اندازی سرور MCP

۱. ابتدا یک کلید دسترسی (API Key) جدید در جدول زیر بسازید.

۲. اتصال مستقیم در ویرایشگر Cursor (توصیه شده):

به راحتی می‌توانید تنظیمات زیر را به فایل `mcp.json` در مسیر `.cursor/mcp.json` پروژه خود اضافه کنید: 

"mcpServers": {
  "shottt": {
    "type": "sse",
    "url": "{{ mcpUrl }}?apiKey=YOUR_API_KEY"
  }
}

همچنین می‌توانید از منوی Settings > Features > MCP در Cursor یک سرور جدید با نام دلخواه (مثلاً shottt)، نوع SSE و با آدرس و کلید دسترسی فوق ایجاد کنید.

    «کدام مواد اولیه در انبار رو به اتمام است؟» یا «تراکنش خروج آرد گندم به میزان ۵ کیلوگرم ثبت کن»

    «یک کد تخفیف جدید با نام YALDA و تخفیف ۲۰٪ برای فردا بساز»
  • 📈 تحلیل پرفروش‌ترین‌ها:
    «پرفروش‌ترین غذاهای شعبه مرکزی در ماه اخیر چه چیزهایی بودند؟»
  • ⏱️ وضعیت تحویل سفارش:

مراحل راه‌اندازی
  1. ابتدا یک کلید دسترسی (API Key) جدید با تعیین دسترسی‌های مورد نیاز در ستون مقابل بسازید.
  2. لینک مشخصات OpenAPI بالا را کپی کرده و در بخش پیکربندی هوش مصنوعی یا ربات خود وارد کنید.
  3. نوع احراز هویت را روی API Key و در هدر (Header) با نام X-Shop-API-Key قرار دهید.
  4. مقدار کلید ساخته شده را به عنوان مقدار هدر قرار دهید.

    «مجموع فروش دیروز چقدر بود؟» یا «پرفروش‌ترین کالاها را نام ببر»

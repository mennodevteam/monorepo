# Agent Skills Directory

This directory is a placeholder for future AI agent skills and custom helper scripts.

## Structure of Skills

Each subfolder inside this directory represents a standalone skill. A skill contains:
1. **`SKILL.md`**: The main documentation and instructions for the skill.
2. **`scripts/`**: Executable scripts (Node/Python/Shell) helper tools.
3. **`resources/`**: Templates, assets, or static configurations.
4. **`examples/`**: Code snippets showing how to execute/use the skill.

## Conventions

- **Document First**: Every skill must have a clear `SKILL.md` explaining its intent, arguments, inputs/outputs, and how to verify its execution.
- **Sandboxed**: Scripts should only execute within the context of the workspace directory.
